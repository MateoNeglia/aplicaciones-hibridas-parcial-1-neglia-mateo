Bienvenido a la API de Relicario

Relicario es una aplicación dedicada a la compra y venta de coleccionables, donde los usuarios pueden registrarse, iniciar sesión y buscar coleccionables por nicho.

La API está diseñada para ser utilizada por la aplicación móvil y web de Relicario, permitiendo a los usuarios interactuar con la plataforma de manera eficiente.

Este es el servicio Backend para la APP Relicario, provee APIS para el manejo de usuarios, autenticación, y el manejo de Nichos y Relicarios además de la búsqueda de Coleccionables

IMPORTANTE: Para Correr la APP desde el front bajarse el siguiente REPO y seguir las instrucciones.

Endpoints

  • POST /api/auth/register

    DESCRIPCIÓN: Registra una nueva cuenta.

    Requerimientos del Request:

    • Body (JSON): 
      
{
  "name": "string (min 2 caractéres, no-numéricos)",
  "lastname": "string (min 2 caractéres, no-numéricos)",
  "username": "string (3-30 caractéres)",
  "email": "string (email válido)",
  "password": "string (min 6 caractéres)",
  "role": "string (opcional, 'user' or 'admin', default: 'user')"
}

    Respuestas esperadas:

    • 201 Created: User created successfully. 
      
{
  "user": {
    "_id": "string",
    "name": "string",
    "lastname": "string",
    "username": "string",
    "email": "string",
    "role": "string"
  },
  "accessToken": "string",
  "refreshToken": "string"
}
    • 400 Bad Request: Input inválido(En este caso, si se manda un nombre sólo de números). 
      
{
  "message": "El nombre no puede ser solo números, El correo es obligatorio"
}
    • 409 Conflict: Si el email o el usuario ya existen. 
      
{
  "message": "El correo ya está en uso, El nombre de usuario ya está en uso"
}
  • POST /api/auth/login

    DESCRIPCIÓN: Autentica al usuario y devuelve un access y refresh token.

    Requerimientos del Request:

    • Body (JSON): 
      
{
  "identifier": "string (email or username)",
  "password": "string"
}

    Respuestas esperadas:

    • 200 OK: Login successful. 
      
{
"user": {
"_id": "string",
"name": "string",
"lastname": "string",
"username": "string",
"email": "string",
"role": "string"
},
"accessToken": "string",
"refreshToken": "string"
}
    • 400 Bad Request: Missing or invalid fields. 
      
{
  "message": "El correo o nombre de usuario es obligatorio, La contraseña es obligatoria"
}
    • 401 Unauthorized: Invalid credentials. 
      
{
  "message": "Invalid identifier or password"
}
  • DELETE /api/auth/users/:id

    DESCRIPCIÓN: Borra a un Usuario por ID, sólo puede ser accedido por el mismo usuario a borrarse o el admin.

    Requerimientos del Request:

    • Params: id (MongoDB ObjectId)
    • Headers: Authorization: Bearer <token>

    Respuestas esperadas:

    • 204 No Content: User deleted successfully.
    • 401 Unauthorized: Token perdido o inválido. 
      
{
  "message": "Authentication required"
}
    • 403 Forbidden: El usuario no es Admin. 
      
{
  "message": "Admin access required"
}
    • 404 Not Found: Usuario no encontrado. 
      
{
  "message": "Usuario no encontrado"
}
